SOLEVERSE website project

Files:
- index.html       Home page with featured shoe cards
- sneakers.html    Sneakers listing with search, filters and sorting
- product.html     Product details, size, colour, quantity and Add to Cart
- checkout.html    Checkout form and order summary
- contact.html     Contact form
- style.css        Responsive styling, gradient backgrounds, card hover and light/dark themes
- script.js        Theme toggle, 15-product catalogue, filters, cart and form interactions
- images/          Add your own shoe photos here (shoe-01.jpg through shoe-15.jpg)

How to run:
1. Extract the ZIP file.
2. Keep all HTML, CSS, JS files and the images folder together.
3. Double-click index.html or open the folder in VS Code and use Live Server.
4. Use the Light/Dark button in the navbar to switch themes. Your selected theme is saved in the browser.
5. Add up to 15 product photos in the images folder. Use the exact filenames listed in images/README.txt.
6. For deployment, upload the complete project folder, including images, to your hosting provider.

The shop displays a maximum of 15 product cards. The cart uses browser localStorage. Contact and order submission are demo interactions and are not connected to a real payment gateway or backend.
